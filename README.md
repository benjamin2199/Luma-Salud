DESCRIPCIÓN DEL PROYECTO

El proyecto consiste en el desarrollo de un MVP web demostrativo de Luma Salud, orientado a simular el proceso de gestión de citas médicas para el caso de ClinicaSalud.

La aplicación permite consultar la disponibilidad médica, registrar reservas, confirmar citas y modificar o cancelar reservas existentes. El sistema utiliza datos ficticios y almacenamiento local para demostrar el flujo principal de agendamiento y gestión de citas médicas.

La demo fue desarrollada con HTML5, CSS3 y JavaScript, y está publicada mediante GitHub Pages para facilitar el acceso y la demostración del funcionamiento del MVP.

RESULTADOS DE LA PRUEBA

La demo permite visualizar y probar el flujo principal del MVP correspondiente a las historias de usuario HU-01, HU-02, 
HU-03 y HU-04: consulta de disponibilidad, registro de reservas, confirmación de citas y modificación o cancelación de reservas.

La aplicación utiliza datos ficticios y almacenamiento mediante localStorage, por lo que la información se conserva localmente en 
el navegador y no se sincroniza entre distintos dispositivos.

El MVP tiene fines demostrativos y no corresponde a un sistema clínico integrado con los sistemas reales de ClinicaSalud. Por lo 
tanto, su funcionamiento no acredita mejoras en indicadores operacionales reales ni permite gestionar información clínica real.
